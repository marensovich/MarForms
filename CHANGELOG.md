# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-20

Первая версия MarForms: формы заявок для Discord-серверов с проверкой ролей, очередью
модерации, отчётами в каналы и журналом действий.

### Для игроков

- Вход через Discord без паролей: запрашиваются только `identify` и `guilds`.
- Публичная форма по ссылке `/f/<адрес>`: шапка с сервером, бейджи срока и лимита, разделы,
  индикатор прогресса, проверка полей при уходе с поля и при отправке.
- Черновик ответов сохраняется в браузере и восстанавливается при повторном открытии.
- Понятный экран на каждый случай отказа: нужен вход, не участник сервера, бан на сервере,
  нет нужной роли, есть запрещённая роль, роли не проверились, приём ещё не начался
  (с кнопкой «Напомнить в Discord»), форма закрыта или в архиве, лимит исчерпан, аккаунт ограничен.
- Страница «Заявка отправлена» с номером заявки и ожидаемым сроком.
- «Мои заявки»: статусы, ответы и комментарий модератора; «Доработать и отправить» для заявок,
  возвращённых на доработку.
- Решение по заявке приходит личным сообщением от бота.
- Анонимные формы без входа, с предупреждением о рисках для владельца.

### Конструктор форм

- Пошаговый мастер новой формы и редактор с вкладками «Основное», «Поля», «Доступ»,
  «Уведомления», «Сообщение».
- 15 типов полей: короткий и длинный текст, число, email, телефон, ссылка, дата, время,
  дата-время, список, радиокнопки, чекбоксы, мультивыбор, да/нет, оценка 1–5, файлы,
  а также разделы.
- Перетаскивание полей, живой холст формы и инспектор поля с ограничениями по типу.
- Условная логика «показать, если»: равно, не равно, содержит, заполнено, больше, меньше.
  Скрытые поля не проверяются и не отправляются.
- Загрузка файлов до 25 МБ с выбором допустимых типов и количества.
- Доступ: «Все», «Участники сервера», «Определённые роли» (разрешённые и запрещённые роли,
  запрет сильнее разрешения), «Анонимно».
- Расписание открытия и закрытия приёма, лимит заявок на человека.
- Автосохранение с индикатором; правки опубликованной формы копятся в черновике до
  «Опубликовать изменения»; предупреждение, если форму сохранил кто-то другой.
- Проверка перед публикацией со списком проблем и переходом к полю.
- Предпросмотр в рамке компьютера или телефона, в том числе от имени участника с выбранными ролями.
- Заявка хранит снимок вопросов: правка формы не меняет уже отправленные ответы.
- Проверка заявок на сайте включается для каждой формы отдельно; без неё форма просто
  присылает ответы в Discord.

### Уведомления в Discord

- Бот сам создаёт вебхук в выбранном канале и присылает туда приветственное сообщение;
  можно и вставить адрес вебхука вручную.
- События по каждому каналу: новые заявки и решения модераторов.
- Вкладка «Сообщение»: общий текст для всех каналов и свой текст в каждом канале,
  упоминание ролей, переменные (`{user.mention}`, `{form.title}`, `{server.name}` и другие).
- Своё оформление embed в каждом канале: цвет, заголовок и ссылка, описание, автор,
  миниатюра и картинка, подвал и время, имя и аватар отправителя; копирование оформления
  в остальные каналы.
- Живой предпросмотр отчёта в виде сообщения Discord.
- Состояние каждого вебхука (работает, с перебоями, недействителен), дата последней доставки,
  тестовая отправка и пересоздание удалённого вебхука одной кнопкой.
- Доставка через очередь с повторами: временный сбой Discord не теряет отчёты и личные сообщения.
- Решение модератора приходит отдельным сообщением в каналы, подписанные на решения.

### Кабинет сервера

- «Мои серверы»: карточки серверов, роль, состояние бота с подсказкой «Выдать права» или
  «Пригласить снова», поиск и фильтры.
- Подключение сервера: приглашение бота и мастер первой настройки.
- Вкладки сервера: «Формы», «Заявки», «Журнал», «Модераторы», «Баны», «Настройки».
- «Формы»: статусы «Черновик», «Опубликована», «Закрыта», «Архив» и переходы между ними,
  копирование ссылки, предупреждение о неработающих уведомлениях, выгрузка ответов в CSV.
- «Заявки»: очередь с фильтрами и поиском, панель заявки с ответами по разделам, файлами,
  текущими ролями автора и историей решений; «Принять», «Отклонить», «На доработку»
  с комментарием, «Пересмотреть решение»; защита от двух решений по одной заявке.
- «Журнал»: кто и когда что сделал на сервере; серия правок одной формы сворачивается
  в одну запись («15:25 – 15:29 Форма изменена»).
- «Модераторы»: добавление по Discord ID или нику, доступ к отдельным формам, удаление
  с подтверждением.
- «Баны»: бан на срок или навсегда с причиной, которую видит пользователь; бан закрывает
  все формы сервера.
- «Настройки»: админ-роли (их участники управляют сервером в MarForms), канал логов
  в категории MarForms с зеркалом журнала, профиль бота на этом сервере (ник, аватар,
  баннер, описание).
- Колокольчик уведомлений, командная палитра (Ctrl/⌘ + K) с поиском и быстрыми действиями.
- Упрощённая мобильная версия: серверы и очередь заявок с решениями.

### Администрирование платформы

- «Формы» и «Заявки» по всем серверам с KPI, фильтрами, массовыми действиями и CSV.
- «Пользователи»: роли платформы, тайм-ауты с пресетами, баны и разбаны с историей;
  иерархия не даёт ограничить равного или старшего.
- «Роли»: матрица прав по областям, создание с копированием прав, предупреждение при удалении.
- «Журнал»: все действия платформы с живой лентой, фильтрами и разворотом изменений
  «было / стало».
- «Система»: CPU, RAM и диск с графиками, версия и коммит, очередь фоновых задач,
  здоровье вебхуков, проверка обновлений по релизам GitHub.
- «Настройки»: название и контакты, вебхук и фильтры журнала, общий embed с предпросмотром,
  текст для ограниченных пользователей, статус бота (онлайн-состояние и активность),
  вебхук обратной связи.
- Страница «Обратная связь» для всех: отдельные вопросы для бага, идеи, проблемы
  и прочего, отправка в вебхук команды.

### Интерфейс

- Русский и английский языки, светлая и тёмная темы.
- Интерфейс по утверждённым макетам и собственному UI-киту.
- Доступность: ошибки привязаны к полям, видимый фокус, управление с клавиатуры.

### Безопасность и надёжность

- Токены Discord и адреса вебхуков зашифрованы AES-GCM; в API токены вебхуков скрыты.
- Вебхуки собираются заново только на `discord.com`, ссылки в embed проверяются при
  сохранении (защита от SSRF и от отказа Discord при доставке).
- Лимиты запросов по IP на публичные эндпоинты, вход и загрузку файлов.
- Выход на всех устройствах отзывает сессии; смена прав завершает старую сессию.
- Оптимистичные блокировки форм и заявок, идемпотентная отправка формы.
- 39 миграций Flyway, тесты бэкенда на H2 и на настоящем Postgres (Testcontainers),
  тесты фронтенда на Vitest, CI в GitHub Actions.

### Доставка

- Один Docker-образ `ghcr.io/marensovich/marforms`: сайт и API на одном порту 8090, проверка
  здоровья, сжатие ответов, доверие `X-Forwarded-*` только из частных сетей за TLS-прокси.
  Запуск: `docker run -p 8090:8090 --env-file .env marforms`.
- `docker-compose.prod.yml`: образ и Postgres. Тег `vX.Y.Z` публикует образ в GitHub Packages.
- `install.sh`: спрашивает адрес сайта, данные приложения Discord, токен бота (и проверяет его
  в Discord) и ID главного администратора, генерирует пароль базы и ключи шифрования, пишет
  `.env` с доступом только для владельца и запускает MarForms, дожидаясь проверки здоровья.
  Повторный запуск не трогает существующий `.env`.
- `ADMIN_DISCORD_IDS`: Discord ID первых администраторов получают системную роль при входе.
